# Security Policy

Please report suspected credential exposure or security vulnerabilities privately to the repository owner through GitHub. Do not include real tokens, Wi-Fi credentials, audio, transcripts, signed URLs, database dumps, or device Flash/NVS exports in an issue.

Before sharing logs or patches:

1. Remove personal recordings and transcripts.
2. Replace device, project, record, and review identifiers with synthetic values.
3. Revoke any credential that may have been exposed.
4. Run `make public-audit`.

Only the latest tagged release receives security fixes. This personal project does not provide a formal response-time guarantee.
